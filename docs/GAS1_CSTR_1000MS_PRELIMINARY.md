# Gas1 CSTR 1000 ms 初步确认报告

- **状态：初步数值确认，不是最终机理认证结果**
- **日期：2026-09-21**
- **参考时间：1000 ms**

## 1. 初步结论

当前将 `1000 ms` 作为 Gas1 CSTR 工况的初步确认时间点。

在 `tau_res = 1 ms`、正值投影诊断积分模式下，1000 ms 末端的 NH₃
浓度为：

```text
NH3 = 1.5447576e8 cm^-3
```

从 100 ms 到 1000 ms，NH₃ 末端浓度只变化约 `1.00e2 cm^-3`，相对变化约
`6.48e-7`；因此在当前数值处理下，系统在 100 ms 后已经进入近似平台，
1000 ms 可以作为后续图表和工况比较的参考时间点。

这只是“当前模型和当前数值稳定性处理下”的初步确认。由于正值投影模式
相对于原始有界 DVODE 轨迹改变了 NH₃ 绝对值，尚不能把该浓度视为最终
经交叉积分器认证的机理预测。

## 2. 工况与模型边界

| 项目 | 设置 |
|---|---|
| 反应器 | 气相 0D CSTR |
| 停留时间 | `tau_res = 1 ms` |
| 压力 | `1 atm` (`101325 Pa`) |
| 初始/进料温度 | `400 K` |
| 进料组成 | `N2:H2 = 1:1`，各 `x = 0.5` |
| 还原场 | 开启 `50 Td`，关闭 `0 Td` |
| 频率 | `10 kHz` |
| 占空比 | `20%` |
| 电子密度 | 固定 `1.17e8 cm^-3` |
| 气体加热 | 禁用 |
| 热力学边界 | 定容 |
| 壁面驰豫 | 启用 |
| 表面反应 | 禁用 |
| CSTR 流动范围 | 气相重物种；电子和表面态排除 |

CSTR 气相物种方程采用：

\[
\frac{dn_i}{dt}=\omega_i+\frac{n_{i,\mathrm{feed}}-n_i}{\tau_{res}}.
\]

电子密度保持处方值，表面态不随 CSTR 进出流动。该模型是均匀 0D
近似，不包含空间梯度、径向输运或真实出口组成分布。

## 3. 1000 ms 结果

### 3.1 正值投影诊断模式

运行配置使用：

- `solver_time_mode: phase_local`
- `species_tolerance_mode: positive_unbounded`
- 并行任务数：`3`
- 每 `100` 个脉冲周期写出一次结果

1000 ms 对应 `10000` 个脉冲周期。结果检查如下：

| 检查项 | 结果 |
|---|---:|
| native 返回码 | `0` |
| 最终时间 | `0.999999999991486 s` |
| 相位/时间 CSV 行数 | `201` |
| 物种端点行数 | `8643` |
| 气相物种数 | `43` |
| 反应速率记录数 | `467` |
| DVODE solver error | `0` |
| `T + H = T` 告警 | `0` |
| 采样物种负密度 | `0` |

1000 ms 最后一个周期的两个相位端点为：

| 相位 | 还原场 | NH₃ (cm⁻³) |
|---|---:|---:|
| 放电结束 | `50 Td` | `1.5445466e8` |
| afterglow 结束 | `0 Td` | `1.5447576e8` |

同一周期内的相位差约为 `2.11e4 cm^-3`，相对末端浓度约
`1.37e-4`，说明仍存在脉冲相位调制，但慢时间包络已经基本稳定。

### 3.2 原始标量有界模式对照

原始 CSTR 标量有界 DVODE 运行在 1000 ms 的结果为：

| 项目 | 标量有界基线 |
|---|---:|
| NH₃ 末端浓度 | `1.7208245e8 cm^-3` |
| `T + H = T` 告警 | `67383` |
| DVODE solver error | `0` |
| 数值质量门 | 未通过 |

正值投影诊断模式得到的 NH₃ 比该基线低约 `10.23%`。这说明告警处理
并非单纯的日志过滤，而是改变了低密度物种的数值轨迹；因此当前应把
`1.5447576e8 cm^-3` 标记为“数值稳定性诊断值”，而不是最终认证值。

## 4. `T + H = T` 的处理

已确认告警来自 DVODE 非负边界回缩路径：当激发态、自由基或离子密度
接近零时，试探步可能越过下界，DVODE 会不断将步长减半；步长达到机器
精度后出现 `T + H = T`。

当前诊断模式采取三项处理：

1. 不启用会触发机器精度回缩的 DVODE 非负边界约束；
2. 反应速率和 CSTR 流项使用非负试探密度；
3. 接受步之后将物种密度投影回非负区间。

该处理消除了告警，但因为它不是 DVODE 原生正性保持算法，仍需独立
积分器或变量变换方法进行交叉验证。

## 6. 当前使用建议

后续初步分析可以统一使用 `1000 ms` 的 afterglow 结束值作为参考点，
同时保留放电结束值用于相位对比。对外或论文级结果暂时不要只报告
单一 NH₃ 绝对浓度；应同时注明：

- 使用的是 CSTR 0D 模型；
- 停留时间为 `1 ms`；
- 表面反应关闭、壁面驰豫开启；
- 当前值来自 `positive_unbounded` 数值稳定性诊断模式；
- BOLSIG 数据库使用了追加详细平衡逆过程的 diagnostic-only 构建。

下一步应使用具备原生正性保持能力的积分器，或进行独立的变量变换
积分，并与本报告的 1000 ms 结果比较后，再决定是否将该浓度提升为
正式结果。
